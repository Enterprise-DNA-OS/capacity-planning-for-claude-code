# weekly-review

Draft Monday review from capacity, stale data, changes and follow-ups.

Read CLAUDE.md first. Use `npm run capacity -- weekly-review` with the required values from the operator. Supported flags: none; add `--json` for machine reads. Run `npm run capacity -- help` for the full command list.

Present the returned records, explain missing data and name the owner of the next step.

The script reads capacity-review, stale-data, change-review and actions-due. Present the generated draft in chat. It sends nothing.
