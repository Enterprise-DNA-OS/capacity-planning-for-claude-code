# stale-data

Find missing, stale or short measurement windows.

Read CLAUDE.md first. Use `npm run capacity -- stale-data` with the required values from the operator. Supported flags: none; add `--json` for machine reads. Run `npm run capacity -- help` for the full command list.

Present the returned records, explain missing data and name the owner of the next step.

Use the evidence and scope notes in docs/compliance.md. Do not send messages or perform infrastructure operations.
