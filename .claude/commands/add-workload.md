# add-workload

Record a workload and its current allocation.

Read CLAUDE.md first. Use `npm run capacity -- add-workload` with the required values from the operator. Supported flags: `--cluster`, `--code`, `--name`, `--owner`, `--cpu`, `--memory`, `--critical`, `--actor`; add `--json` for machine reads. Run `npm run capacity -- help` for the full command list.
